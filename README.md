# rag-chatbot-project# Prachinburi Local Travel & Cultural Guide - RAG Chatbot

เว็บแอปพลิเคชันแนะนำข้อมูลการท่องเที่ยว ประวัติศาสตร์ วัฒนธรรม และของดีประจำจังหวัดปราจีนบุรี พัฒนาด้วยเทคนิค Retrieval-Augmented Generation (RAG)

## 1. แนวคิดของระบบ (Domain Concept)
ระบบนี้ถูกออกแบบมาเพื่อเป็นไกด์ดิจิทัลอัจฉริยะ ให้ข้อมูลที่ถูกต้อง แม่นยำ และตรวจสอบแหล่งอ้างอิงได้ ช่วยแก้ปัญหา LLM สร้างข้อมูลเท็จ (Hallucination) เรื่องเวลาเปิด-ปิด ค่าเข้าชม หรือพิกัดสถานที่ท่องเที่ยว โดยระบบจะค้นหาข้อมูลจากคลังเอกสารท้องถิ่นจริงก่อนส่งให้โมเดลสรุปคำตอบ

## 2. แหล่งที่มาของเอกสาร (Knowledge Base)
เอกสารรวบรวมไว้ในโฟลเดอร์ `data/` จำนวน 10 ไฟล์ ความยาวรวมกว่า 16,000 ตัวอักษร อ้างอิงจากข้อมูลการท่องเที่ยวแห่งประเทศไทย (ททท.) และเทศบาลเมืองปราจีนบุรี:
- `01_national_parks.txt`: ข้อมูลอุทยานแห่งชาติเขาใหญ่ ทับลาน เขื่อนห้วยโสมง
- `02_temples_and_faith.txt`: วัดแก้วพิจิตร รอยพระพุทธบาทคู่ ต้นพระศรีมหาโพธิ์
- `03_historical_sites.txt`: พิพิธภัณฑสถานแห่งชาติ ปราจีนบุรี ตึกเจ้าพระยาอภัยภูเบศร เมืองโบราณศรีมโหสถ
- `04_festivals_and_events.txt`: งานล่องแก่งหินเพิง งานวันเกษตรและทุเรียนปราจีน
- `05_local_food_and_restaurants.txt`: กุ้งแม่น้ำปราจีนบุรี ร้านอาหารสมุนไพรอภัยภูเบศร
- `06_souvenirs_and_otop.txt`: ทุเรียน GI ปราจีนบุรี ยาสมุนไพร เสื่อกกบ้านสร้าง
- `07_transportation.txt`: ตารางรถไฟสายตะวันออก รถมินิบัสหมอชิต รถสองแถว
- `08_accommodations_and_camping.txt`: ลานกางเต็นท์ลำตะคอง รีสอร์ตริมแม่น้ำ
- `09_adventure_and_rafting.txt`: ระดับความยากการล่องแก่งหินเพิง เส้นทางปั่นจักรยาน
- `10_emergency_and_visitor_centers.txt`: เบอร์โทรฉุกเฉิน โรงพยาบาล ตำรวจท่องเที่ยว

## 3. สถาปัตยกรรมทางเทคนิค (Technical Architecture)
1. **Document Loading & Chunking**: ทำความสะอาดข้อความด้วย Regex และแบ่งท่อนขนาด 450 ตัวอักษร (Overlap 80)
2. **Embedding & Vector Database**: ฝังเวกเตอร์ด้วย `paraphrase-multilingual-MiniLM-L12-v2` และจัดทำดัชนีสืบค้นผ่าน `FAISS` (IndexFlatIP)
3. **Prompt Engineering**: ใช้กฎเหล็กบังคับให้ LLM ตอบจากบริบทเท่านั้น ระบุแหล่งที่มา และตอบปฏิเสธว่า "ไม่พบข้อมูลนี้ในเอกสารคลังความรู้" หากไม่มีข้อมูล
4. **LLM Generation**: เรียกใช้โมเดลผ่าน Groq API เพื่อสร้างคำตอบที่รวดเร็ว
5. **Chat Interface**: หน้าจอสนทนาโต้ตอบต่อเนื่องด้วย Streamlit พร้อมกล่องขยายแสดงเอกสารอ้างอิงและคะแนนความคล้ายคลึง

กฎการตอบคำถาม:
